# OlafAndreas/homebrew-tap

Homebrew formulae for OlafAndreas's tools.

```bash
brew install olafandreas/tap/xcflow
```

| Formula | What it is |
|---|---|
| [xcflow](https://github.com/OlafAndreas/xcflow) | Xcode Cloud workflows as JSON files in your repo. |

Formulae are updated by each tool's release workflow.
